# Мельница — первый растровый пакет здания

Для **игровой отрисовки** используются настоящие рисунки, вырезанные из двух утверждённых пользователем спрайт-листов, а **не прежние упрощённые SVG**.

## Игровые изображения

| Файл | Содержание |
| --- | --- |
| `mill-states-start.webp` | Разметка, каркас, стены, почти готовая мельница, готовые состояния, зерно |
| `mill-states-end.webp` | Мука, повреждения, свежие, старые и заросшие руины, восстановление |
| `mill-parts.webp` | Дополнительные детали и миниатюры для внутреннего режима |
| `mill-detailed-body.webp` | Новый корпус 360×316 из исходных утверждённых частей без крупной пустой площадки |
| `mill-detailed-rotor.webp` | Отдельные крылья 239×227 без неподвижного ротора на корпусе |

Три первоначальных атласа — прозрачные WebP **704 × 352**, ячейки **176 × 176**. Основной корпус и крылья теперь хранятся отдельно в полном разрешении, чтобы при отрисовке не терялась детализация. Схема расположения и происхождение указаны в `mill-pack.js` и `manifest.json`. Исходные PNG прикреплены к рабочему диалогу, их SHA-256 зафиксированы в манифесте.

Готовая мельница всегда рисуется как **детализированный корпус + ровно один отдельный ротор**. У работающей мельницы вращается ротор, у неработающей или на паузе он неподвижен. Внешний фасад не перекрывается нарисованными снаружи мельником и жерновами: они показываются в панели «Внутренняя мастерская».

Стадии строительства и виды руин берутся из исходного **второго растрового спрайт-листа**. Руины занимают участок до реставрации или расчистки. Хозяйство использует реальные локальные остатки `grain` и `flour`.

### Примечания

- Старые `layers/*.svg` сохранены лишь для истории, игровой рендер их больше не загружает.
- Растровые исходники проходят удаление красно-жёлтых пикселей с почти нулевой прозрачностью.
- Комбинированный корпус собран из иллюстраций башни, пристройки, крыши и фундамента; это не новая процедурная модель.
- Для следующих построек применяется та же архитектура, но собственные утверждённые растровые ассеты.

### Исправление масштаба и совмещения

У мельницы нет огромной пустой площадки: фундамент отрисовывается как часть башни и пристройки. Ступица находится на пикселе **(135,148)** в исходном теле 360×316; один ротор масштабируется относительно тела и вращается строго вокруг неё. Пропорции проверяются unit- и браузерными тестами.
