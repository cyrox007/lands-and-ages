# Мельница — эталонный пакет здания

Это **первое** здание, переведённое на независимые прозрачные игровые слои. Другие здания остаются без изменений.

## Состав

- `manifest.json` — справочник для художника и экспортёра, `mill-pack.js` в корне проекта — исполняемый контракт.
- `layers/` — 17 самостоятельных SVG. Все слои имеют общую систему координат 320×320; ротор хранится в собственных координатах 180×180 с осью 90×90.
- Фундамент, корпус, кровля, ротор, реквизит, мешки зерна, мука, мельник и жернова отдельно переключаются рендером.
- Стройка: разметка, фундамент, каркас, стены, крыша. Только после доставки материалов и работы строителей.
- Производство: носильщик доставляет зерно в локальный `b.goods.grain`, мельник перерабатывает по рецепту, мука появляется в `b.goods.flour` и ждёт вывоза.
- Повреждение, свежие руины, старые руины, заросшие руины; каждое состояние остаётся на занятой клетке.
- Восстановление требует 24 монеты, 3 доски и 2 камня; затем свободный строитель выполняет работы в течение 16 игровых секунд.

## Графика и исходник

Утверждённый концепт-лист от 2026-11-02 в рабочем диалоге — художественный ориентир. **В этом PR он не выдаётся за готовый прозрачный игровой спрайт**: новые отдельные SVG отрисованы в близкой палитре, но ещё требуют художественной доводки до качества концепта. Именно для такой замены пакет хранит части отдельно.

## Правила для следующих зданий

Не переносить состояния и рисунки мельницы в другие строения копированием. Каждое здание получает собственный пакет: единый якорь, слои, локальные входы/выходы, анимации, строительство, повреждения, руины и тесты сохранения.
