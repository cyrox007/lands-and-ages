# Ресурсы: единый игровой атлас

Атлас `construction-resources.webp` **1600×640 px**, сетка 5×2 с ячейкой 320×320. Это нарезанные ресурсы из утверждённого пользователем изображения `ресурсы_средневековой_стратегии.png`, без замены на упрощённые SVG.

| Ряд | Столбцы слева направо |
| --- | --- |
| 1 | Доски (мало), доски (много), камень (мало), камень (много), брёвна (мало) |
| 2 | Брёвна (много), пшеница (мало), пшеница (много), мука (мало), мука (много) |

Контракт `resource-pack.js` возвращает координаты каждого фрагмента, а `ui.js` рисует:
- **на стройплощадке** только доставленные доски и камень, основываясь на `site.goods`;
- при продвижении строительства объём лежащих материалов уменьшается по фактическому `site.progress`;
- **в руках носильщиков** брёвна, доски, камень, пшеницу или мешки муки в зависимости от `carrying.res`.

Игровую симуляцию, расходы и сохранения изображения не изменяют. На паузе состояние материалов не меняется. Для овощей и хлеба пока сохраняется существующий вид груза, пока не будут утверждены их собственные рисунки.

Происхождение оригинального PNG: SHA-256 `3c21c9924383143ba217ce105b6e3094ebbea61c75805d3065fa139ceb150681`. Исходник сохранён в материалах диалога, игровой WebP находится в этом каталоге.

Подготовка: исходный альфа-канал и детали сохранены; удалена яркая красная кайма и почти прозрачный шум. Внешние тени и масштабирование выполняются игровым Canvas.
