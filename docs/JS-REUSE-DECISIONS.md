# Что забрали из JS-прототипа в Godot

**Решение владельца, 12.11.2026:** старый браузерный билд больше не поддерживается.
Из него переносим только доказавшие пользу игровые правила; прочие файлы
удаляются из рабочего дерева. Историческая реализация осталась в Git.

| JS-источник | Полезное правило | Состояние в Godot |
| --- | --- | --- |
| `navigation.js` | Четырёхсвязный маршрут без прохода сквозь препятствия и доступный внешний порт постройки | `world_resource_path.gd` уже проверяет воду/склон/сушу; `world_road_topology.gd` добавляет геометрию внешних портов. Подключение работников — 13.3 |
| `visual-model.js` | 16 сочетаний дорожных соединений, прямая, поворот, T-узел | `world_road_topology.gd` и `world_road_topology_13_smoke.gd`. Это только геометрический контракт, не готовая система строительства дорог (13.2) |
| `engine.js` | Ограниченное сырьё, физическая доставка без телепортации, расход материалов при строительстве | Уже есть в `world_first_economy.gd`, `world_resource_industry.gd` и `world_save.gd`. Вторую экономику не создаём |
| `tests/world-baseline.test.cjs` | Детерминированные seed, проверяемое списание и сохранения | Подход используют существующие тесты Godot на ресурсы, популяции и первый хозяйственный цикл |

**Не переносим:** Canvas, HTML/CSS, генератор карты 26×18, отдельную
браузерную систему хранения `localStorage`, 2D-атласы, старые
сценарные исключения и Node-сборку.

Для просмотра исходного кода без восстановления второго runtime:
`git show 53f7a047:engine.js`,
`git show 53f7a047:navigation.js`,
`git show 53f7a047:visual-model.js`.

Ни браузерные сохранения v1–v3, ни старые ресурсы не импортируются
в `WorldSave` автоматически. Правила Godot должны опираться на его
единую карту, физические источники и действующий реестр построек.
