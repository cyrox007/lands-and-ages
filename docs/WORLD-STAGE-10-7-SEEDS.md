# Этап 10.7 — проверка множества природных карт

## Для чего нужна проверка

Одна демонстрационная карта с seed 1729 недостаточна для принятия
генератора. Цель — найти скрытые ошибки при других формах суши, морей,
островов, руслах рек и распределении природных ресурсов, не навязывая
всем картам один процент воды.

Сценарий `godot/tests/nature_seed_audit.gd` проверяет следующее:

- уникальные ID и корректную принадлежность природных объектов чанкам;
- отсутствие деревьев, кустов и валунов в воде;
- допустимые координаты, конечные высоты и неотрицательный запас;
- стабильный результат генерации для повторного seed;
- одинаковое развитие природы на протяжении восьми игровых дней;
- загрузку и восстановление физического природного слоя;
- статистику площади морской и пригодной суши, числа объектов,
  древесных запасов и **предварительного** числа свободных центров.

Результаты записываются в JSON с показателями min/mean/max/p95
и подробным списком каждого seed. При нарушении инвариантов тест
завершается ошибкой.

## Быстрая и полная проверка

Обычный профильный CI `godot-nature.yml` проверяет **четыре seed**
на карте 96×80 и сохраняет `ecology-seed-smoke`.

Расширенный прогон предусмотрен отдельным workflow
**Этап 10.7 — расширенный аудит природных seed**. Его ручной запуск
через GitHub Actions станет доступен, когда workflow окажется в
ветке по умолчанию **main**; пока разработка ведётся в `develop`,
можно запускать приведённую ниже локальную команду.
Параметры по умолчанию: **100 seed**, карта **128×96**.
Допускается от 1 до 500 seed и размеры от 32 до 256 клеток.

Команда для локального запуска (пример):

```bash
godot --headless --path godot --editor --import --quit
godot --headless --path godot \
  --script res://tests/nature_seed_audit.gd -- \
  --samples=100 --width=128 --height=96 --seed_start=1729
```

Отчёт: `godot/tests/world-ecology-seeds-10.json`.

## Что эта проверка НЕ доказывает

- Число `settlements_r9` — только приближённая оценка
  геометрического размещения начальных центров, не шести стран
  с 30 городами верхнего уровня.
- Отчёт не подтверждает назначение метров на клетку, реальные
  ресурсы каждого государства, проходимость дорог и морской транспорт.
- Время генерации в headless CI нельзя считать FPS, временем
  отображения леса или замером GPU/VRAM пользовательского устройства.
- Пользовательский замер после первого подключения GLB:
  кратковременно 112 FPS на старте, затем 143–144 FPS. Он не заменяет
  отдельный аппаратный аудит для новых усложнённых ассетов.

После утверждения размеров зрелых поселений задачу #103 нужно
дополнить игровым валидатором ёмкости и справедливости шести государств.
