# 0.5.14 — действия поселенцев по профессиям

Анимационный пакет закреплён за профессией. Конкретное действие включается по фазе игровой симуляции, а не по случайному таймеру. Производство и логистика остаются в движке.

## Автономные рабочие

| Профессия | Подключённые действия | Следующий художественный этап |
|---|---|---|
| Носильщик | ожидание, ходьба, перенос фактического груза | загрузка и разгрузка с игровыми задержками |
| Строитель | ожидание, ходьба, фундамент, каркас, крыша | отдельная анимация инструментов, ремонт |
| Лесоруб | ожидание, путь к лесу, рубка, перенос брёвен | посадка деревьев |
| Каменотёс | ожидание, путь к породе, удары по камню, перенос добычи | сортировка камней |
| Земледелец | ожидание, путь к созревшему полю, сбор урожая, перенос | расчистка, посев, уход за полем |

В текущем движке фазы out/work/return/idle реально существуют у лесоруба, каменотёса и земледельца. Строитель меняет действия по фактическому прогрессу стройки. У носильщика погрузка и разгрузка пока происходят мгновенно; соответствующие действия зарегистрированы как контракты, но не проигрываются с задержкой.

## Назначенный персонал зданий

| Предприятие | Действие при активной работе |
|---|---|
| Лесопилка | пиление |
| Мельница | помол (внутренняя графика мельницы остаётся) |
| Пекарня | замес теста |
| Академия | работа с книгой |
| Театр | выступление |
| Рынок | торговля |
| Посольство | письмо |
| Казармы | тренировка |

Второй список — персонал помещений, а не отдельные автономные юниты. Отрисовка выполняется на месте и только когда есть назначенный работник и производство действительно активно.

## Источники графики и ограничения

- Файл profession-actions.js содержит каталог и условия запуска.
- painted-motion.js использует общие утверждённые портреты, различающуюся амплитуду работы и контекстные визуальные эффекты.
- Встроенные в портрет инструменты не дублируются; носильщик использует тело без нарисованного мешка. Настоящий груз рисуется отдельно.
- Ходьба зависит от пройденного расстояния. Пауза останавливает время анимации.
- Это рабочий технический пакет переключения профессиональных действий, **не полноценная покадровая ручная рисовка**. Для каждого дополнительного действия нужны будущие 4 направления × 8 независимых кадров с общей опорой по ступням.
- Подготовка почвы, посев, ремонт и несуществующие автономные маршруты не обозначаются как завершённые механики.

## Приёмка

Unit-тесты проверяют реестр всех 13 профессий и переходы состояний. Chromium проверяет различие фактических пикселей разных профессиональных действий и работающие сценарии на десктопном/мобильном viewport. Ручная художественная и Android-проверка остаётся отдельной задачей.
