# План развития «Земли и эпохи»

## Сделано (технический уровень)

- [x] **0.1** — базовая экономика поселения, производство, носильщики, дороги, сохранения.
- [x] **0.2** — **техническая изометрическая проекция и интеграция восьми статичных 2.5D-спрайтов**, управление камерой. **Это не завершение графического направления.**
- [x] **0.3** — первая небольшая миссия, выбор пути развития, победа, подсказки.
- [x] **0.4** — реальные площадки, доставка досок, строители, строительство во времени, технический показ прогресса через маску готового спрайта и леса. **Полноценные кадры строительства не реализованы.**

## Приоритет: цельная графика (не сделано)

- [ ] **Визуальная основа / Issue #5** — согласованные масштабы и фундаменты; бесшовный грунт и рельеф, соединяемые дороги, объёмные деревья, самостоятельные спрайты профессий, направленная ходьба, осмысленные стадии строительства, рабочие анимации, тени и оптимизированный рендер.
- [ ] Сначала **вертикальный срез**: небольшой участок поселения с землёй, дорогой, домом, деревом, носильщиком и строительством; проверить художественную цельность и производительность, затем расширять набор ассетов.
- [ ] Не считать визуальный этап завершённым по факту появления новых картинок. Критерий — единый узнаваемый игровой мир, анимации с привязкой к симуляции и читаемость на телефоне.

## Следующие этапы

- [ ] **0.4.x / Issue #2** — реальный Android QA: сенсорное управление, FPS/frame time, память, длинные сессии; исправить блокирующий UX.
- [ ] **0.5 / Issues #3–4** — карьер, камень, сложные рецепты строительства, дороги с покрытиями, многоклеточные фундаменты и очередь заказов. Работы по фундаментам и визуальной основе согласовывать, чтобы избежать двойной переделки.
- [ ] **0.6** — логистика больших поселений, специализация складов, рынки, цены, реальные потребности населения.
- [ ] **0.7** — регионы, отдельные поселения, глобальная карта.
- [ ] **0.8+** — полноценные технологии, политика, культура, дипломатия, война и несколько способов победы.

## Принципы

- Игровая логика, внешний вид и анимация — разные слои, но анимация должна соответствовать настоящим изменениям состояния.
- Сначала целостный визуальный вертикальный срез; только затем массовое добавление зданий и производств.
- Не ломать текущие производственные цепочки, сохранения, миссию и интерфейс.
- Тестировать логику, интерфейс, производительность и физическое устройство отдельно.
- Ориентир для Android — стабильное время кадра с системным лимитом 60 FPS, а не максимальный FPS любой ценой.
- Связь с общей авторской вселенной — только фоновая, без раскрытия закрытого канона.
