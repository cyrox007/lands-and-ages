# План развития «Земли и эпохи»

## Завершено

- [x] **0.1** — экономика поселения, производство, носильщики и дороги, сохранения.
- [x] **0.2** — изометрическая 2.5D карта, оптимизированные авторские спрайты, управление камерой.
- [x] **0.3** — первая небольшая миссия, выбор пути развития, победа, подсказки.
- [x] **0.4** — реальное строительство: площадки, доставка досок, строители, время, визуальный прогресс, сохранение стройки.


- [x] **0.4.4** — пройденная дистанция управляет кадрами ходьбы; сохранение направления при остановке; производственные эффекты пяти мастерских видны только во время реальной работы. Это ещё не завершение общего визуального качества. Подробности в `docs/VISUAL-0.4.4.md`.

## Следующие этапы (не реализованы)

- [ ] **0.4.x** — испытание физического Android (сенсорное управление, FPS, память, продолжительные сессии); исправление UX/баланса.
- [ ] **0.5** — камень и карьер, более сложные материалы, дороги с несколькими видами покрытия, многоклеточные фундаменты, очередь стройзаказов.
- [ ] **0.6** — логистика больших поселений, специализация складов, рынки, цены, реальные потребности населения.
- [ ] **0.7** — отдельные посёлки/регионы, глобальная карта и взаимодействие между ними.
- [ ] **0.8+** — технологии, политика, культура, дипломатия, война и несколько способов победы.

## Принципы

- Изменения не должны ломать существующие производственные цепочки, сохранения и миссию.
- Экономическая модель и визуальная анимация — разные слои; никакие товары не возникают просто из эффекта.
- Сначала тестируем логику, затем интерфейс, затем реальное устройство.
- Намёки на общую вселенную — фон, не основа кампании и не спойлер.
