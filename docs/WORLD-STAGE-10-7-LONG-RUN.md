# Этап 10.7 — длительная регрессия экосистемы

Продолжение проверки 100 seed и профиля коллизий (WORLD-STAGE-10-7-PROFILING.md).
Этот тест не добавляет людей, дороги или экономику и не изменяет
законы физической карты.

## Что проверяет автоматический тест

Скрипт godot/tests/nature_long_run_10_7.gd запускает два мира
64×48 с разными seed на **96 игровых суток**. Для каждого создаются две
независимые копии мира, одна из которых периодически восстанавливается
из JSON. При переходах через 24, 48, 72 и 96 суток проверяются:

- тождественность природных, климатических, грунтовых, водных и
  событийных снимков после одинакового количества суток;
- одинаковое развитие растительности при повторной сериализации;
- запись и восстановление реального файла user:// на 48-м дне;
- инварианты ID, возраста, здоровья и неотрицательного запаса древесины;
- отсутствие изменения физического состояния после сборки GPU-чанка
  с близким и дальним уровнем детализации;
- длительность суточного расчёта p50/p95/p99 в headless CPU.

Команда проверки:

~~~sh
godot --headless --path godot --editor --import --quit
godot --headless --path godot \
  --script res://tests/nature_long_run_10_7.gd -- \
  --days=96 --samples=2 --seed_start=1729
~~~

Отчёт godot/tests/world-nature-long-run-10-7.json сохраняется как
артефакт nature-long-run-10-7 в GitHub Actions. Поле hard_errors
должно быть пустым.

## Что тест НЕ подтверждает

96 игровых суток **не равны 30 минутам реальной игры**.
Headless не измеряет GPU, реальный FPS, VRAM или нагрев смартфона.
После успешного CI остаются отдельные испытания 30+ минут
на ПК и Android, смена ракурса во время валки, память,
p50/p95/p99 кадра, визуальные швы, берег и сезонная палитра.
Не закрывать общий этап 10 без этой аппаратной приёмки.
