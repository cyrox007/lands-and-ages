# Этап 11 — регрессия и ускорение суточного климата

Дата: 09.11.2026. Исходный код: [PR #273](https://github.com/cyrox007/lands-and-ages/pull/273).

## Исправленная стоимость

В `Climate._calculate_day` большая карта **256×192** создаёт четыре погодных массива на **49 152** физических клетках. Раньше каждая клетка повторно считала тригонометрию сезонного дня, общеширотный дождевой множитель и один и тот же псевдослучайный хеш узлов погодных фронтов.

Теперь:

- Сезонное значение температуры и суточный вклад ветра вычисляются один раз за день.
- Коэффициент осадков вычисляется один раз на строку широты, а не 256 раз на строку.
- Для двух движущихся фронтов вычисляются редкие опорные узлы `Terrain.hash2` в `PackedFloat64Array`, и соседние клетки используют те же значения; сглаживание `smoothstep/lerpf` остаётся точно прежним.
- При изменении грунта частичная пересборка пересчитывает только затронутые строки; остальные значения не затрагиваются.

Изменены **только вычислительные повторы**. Физическая формула температуры, дождя, гроз, ветра, seed, частичная перестройка, структура `WorldSave` и гидрология не заменены.

## Доказательство точности и измерение

[GitHub Actions CLIMATE-PERF](https://github.com/cyrox007/lands-and-ages/actions/runs/42597930532) запускает настоящий Godot 4.7.2.

Тест `res://tests/climate_day_perf_11_smoke.gd` создаёт одну карту seed 1729, старый и новый экземпляры `Climate`, работающие над одинаковыми исходными полями. Эталон `res://tests/climate_day_legacy_reference.gd` содержит исходную суточную формулу внутри наследника `Climate`, то есть **пишет в такие же свойства-массивы**, как рабочий алгоритм. Во втором цикле порядок измерения меняется местами.

- [x] **Десять** суточных шагов, пять сезонных дат, полное сравнение четырёх массивов по **49 152** значения каждый, без допуска на погрешность.
- [x] Проверка выборочной перестройки трёх широт, включая неизменность четвёртой незатронутой широты.
- [x] Старый алгоритм **1 022 764 мкс** суммарно, новый **388 992 мкс**. Экономия **633 772 мкс**, или **61,97%** на климатической функции.
- [x] [Погодный интеграционный CI](https://github.com/cyrox007/lands-and-ages/actions/runs/42597930476) — успех.

Воспроизведение в установленном Godot 4.7.2:

```sh
godot --headless --path godot --script res://tests/climate_day_perf_11_smoke.gd
```

## Чего этот тест не доказывает

**61,97% относится только к `Climate._calculate_day`, а не ко всему `WorldDayRunner.run_day`.** Остались расчёты поверхности, гидрологии, растений, природных бедствий, огня, согласования и графика. Прежний реальный пользовательский пик суточной физики **533,5 мс** и CI-пик программного OpenGL около **642,3 мс** после данного изменения на том же оборудовании не сравнивались. Для абсолютной оценки полного дня нужен отдельный замер 256×192 на одной и той же машине до/после, а также аппаратные проверки GTX 1650/Android.

Прогресс официального этапа 11 остаётся **5/11 крупных разделов**, пользовательских контрольных возможностей **2/5**. Следующий шаг — измерить полный физический день и проверить, не доминируют ли теперь другие стадии.
