# Этап 12.6 — хищники, добыча и природные бедствия

## Физические пищевые отношения

`wildlife_food_web.gd` содержит региональные популяции **волков** и **лис**, созданные только из настоящей пищевой базы.

- Волки могут охотиться на оленей, кабанов и зайцев; лисы — на зайцев.
- При рождении стаи её допустимая численность зависит от живых травоядных в регионе. Растительный корм хищнику не засчитывается.
- Каждые восемь игровых суток хищники пытаются добыть корм через `WildlifePopulations.consume_prey`; при успехе конкретные особи исчезают из реестра травоядных. **Пустой регион не создаёт добычу.**
- При недостатке корма повышается смертность хищников и не допускается рождение. При доступном корме и свободной кормовой ёмкости рождаемость возможна.
- Стаи мигрируют в соседние регионы только если там есть настоящая добыча, свободная ёмкость и проходимая сухопутная граница. Один хищник остаётся одной особью при переходе.
- Модель хранит численность по регионам — без создания отдельного узла на каждого зверя.

## Природные опасности

`WildlifePopulations.react_hazards` получает события от `WorldDayRunner`: штормы, шквалы, ураганы, смерчи, паводки, лавины, сели, оползни, обвалы и землетрясения.

- Популяции пытаются уйти в соседний регион со свободным кормовым потенциалом.
- Проход по воде и во время паводка не разрешён.
- Сильное бедствие без безопасного выхода может вызвать гибель части животных.
- Хищники реагируют тем же реальным потоком событий.
- Не все бедствия обязаны вызывать гибель: при наличии доступного пути возможна эвакуация.

Эти реакции пока **региональная экологическая модель**, а не индивидуальный искусственный интеллект каждого животного, анимация его бегства или детальная физика охоты.

## Сохранение и проверка

Новый необязательный раздел `food_web` в `WorldSave` хранит численность хищников. Реальная съеденная добыча уже отсутствует в `wildlife`. Оба реестра восстанавливаются до принятия игрового мира; старые сохранения без хищников остаются совместимыми.

```bash
godot --headless --path godot --script res://tests/world_wildlife_food_web_12_smoke.gd
```

Интеграционный тест создаёт живую карту `seed=1729`, прогоняет 32 физических дня, вызывает штатный диагностический шторм из природного `WorldDayRunner`, проверяет массовый баланс добычи и хищников, последствия опасности, сохранение на 19-м дне и продолжение после загрузки.

## Границы этапа

12.6 **не** выполняет добычу мяса и шкур для хозяйства — это 12.7. Одомашнивание без спавна при постройке здания — 12.8. 3D-анимация и звуки — 12.9. Годовые, многосидовые и аппаратные нагрузочные тесты — 12.10. Все они требуют отдельной приёмки.
