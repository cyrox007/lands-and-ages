# Этап 12.5 — реальные популяции диких травоядных

## Модель

`wildlife_populations.gd` хранит численность **по природным регионам** (не одного Godot-узла на животное). Это часть физического мира, а не графическая имитация.

- **Олень, заяц, кабан:** начальные популяции возникают при генерации лишь в регионах, где `wildlife_habitats.gd` подтвердил пригодные участки с кормом, водой и укрытием.
- **Волк и лиса:** пока нет реальной популяции добычи в 12.6, не добавляются. В этих системах нет бесплатного рождения хищников.
- **Каждые 8 игровых дней:** происходят размножение и естественная смертность. Рождаемость ограничена свободной экологической ёмкостью; перенаселение и деградация ареала повышают смертность.
- **Каждые 24 дня:** ёмкость регионов повторно рассчитывается из действующего климата, снегового покрова, воды и растительности. В старых регионах, утративших корм, не создаётся новая популяция.
- **Миграции:** животные переходят в менее загруженный соседний регион, только если реальная общая граница имеет проходимую сухопутную клеточную пару. Миграция сохраняет общее количество особей.
- **Детерминизм:** дробные вероятности рождений и смертей используют фиксированный hash мировой seed, вида, региона и игрового дня. Результат не зависит от FPS, порядка чанков и камеры.
- **Лимиты:** максимум 512 особей одного вида на регион; максимум 4096 регионов; для обычной карты используется лишь несколько десятков записей. Рендер животных отсутствует до 12.9.

## Связь с календарём и сохранениями

После полного расчёта физического дня через `WorldDayRunner` в основной сцене вызывается `wildlife.advance_day(day)`. Новый реестр не изменяет реки, грунт, траву и деревья; только читает их.

Снимок `WorldSave` добавляет раздел `wildlife` с численностью и текущей ёмкостью ареала. При загрузке посреди сезона восстановление не создаёт новые стада и не пересчитывает задним числом достигнутые ёмкости. Повреждённый реестр отклоняется до замены физического мира.

Старые сохранения без раздела `wildlife` сохраняют совместимость и загружаются **без автоматического создания животных**; для них потребуется отдельный контролируемый сценарий миграции данных.

## Программная приёмка

```bash
godot --headless --path godot --script res://tests/world_wildlife_populations_12_smoke.gd
```

Тест запускает реальную карту `seed 1729, 256×192` и физический природный календарь. Проверяет воспроизводимость начального состава, сохранение количества животных при миграции, ограничения численности, запрет поддельных видов, атомарность сохранения на 19-м дне и продолжение физики с идентичными популяциями после загрузки.

**Открытые ограничения:** хищничество, пищевые ресурсы животного происхождения, одомашнивание, анимация стад и сезонные нагрузочные/аппаратные испытания не относятся к 12.5; они идут по 12.6–12.10. Первая реализация популяций не подменяет экономику и население шести государств.

## 12.5+ — возрастные когорты (11.11.2026)

Региональная численность дополнена тремя группами: молодые, взрослые и старые.
Возрастной переход происходит только в прежнем восьмидневном цикле.
Рождение добавляет молодняк, естественная смертность прежде всего
затрагивает старых, охота расходует существующих взрослых, а миграция
переносит возраст без омоложения. Увеличения числа видимых `Node3D` нет.

API `population_at`, `total`, FoodWeb и хозяйства сохранён. В WorldSave
появилось поле `ages` и версия 2 только для подсекции `wildlife`.
Снимки `wildlife` версии 1 принимаются с детерминированной инициализацией
трёх групп без изменения численности. Повреждённые массивы отвергаются
до изменения реестра. Годовые и суточные тесты проверяют равенство
`молодые + взрослые + старые = count` в каждом регионе.
