# Контрольный список Android (ручная проверка)

Устройство: realme 11 Pro+ 5G; принудительный системный лимит 60 FPS — по выбору владельца. Не считать прохождение эмуляции подтверждением теста телефона.

- [ ] `play.html` запускается локально и не запрашивает интернет.
- [ ] Экран и панели помещаются на портретной ширине без горизонтального скролла.
- [ ] Работают тапы по клеткам/зданиям, перемещение карты, масштаб, пауза и скорость.
- [ ] На новой миссии ремонтируется повреждённая дорога; до завершения носильщик по ней не ходит.
- [ ] К стройплощадке доставляются доски; строители работают, процент растёт; здание не возникает целиком сразу.
- [ ] Нельзя построить площадку без подъезда и получить мгновенный результат.
- [ ] Производится хлеб и выполняются все этапы миссии.
- [ ] Сохранить во время стройки, перезапустить страницу, продолжить и завершить её.
- [ ] FPS и время кадра проверены на плотной карте в начале и через 10–15 минут; оценены нагрев и расход батареи.
- [ ] Отмечены все замеченные ошибки/неудобства и внесены в GitHub Issues.

**Условие успешного QA:** весь игровой цикл можно завершить на телефоне без застреваний, потери сохранений и непредсказуемых нажатий. 60 FPS — целевой предел, а не уже подтверждённое измерение.
