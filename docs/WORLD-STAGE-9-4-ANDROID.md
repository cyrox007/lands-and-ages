# Android-проверка мира — отладочный APK этапа 9.4

Автоматическая графическая приёмка (PR #90) умеет снимать кадры мира через Mesa llvmpipe. Но это **программный OpenGL**, а не реальный смартфон. Для следующего этапа проверки нужна установка приложения на Android без ручной сборки на ПК.

## Сборка в GitHub Actions

`.github/workflows/world-android-debug.yml` устанавливает OpenJDK 17, Android SDK и официальные, точно соответствующие движку **Godot 4.7.2** шаблоны экспорта. Экспортируется отдельный APK для **ARM64-v8a** в режиме **GL Compatibility**. Браузерная игра в корне репозитория и её сохранения не затрагиваются.

Конфигурация: `godot/export_presets.cfg` — имя пакета `io.cyrox.landsages.worldqa`, APK (не AAB), ARM64, собственная идентичность тестовой версии.

В каталоге артефактов GitHub Actions должен появиться `world-qa-android-arm64-debug`, включающий:

- `lands-and-ages-world-qa-arm64.apk`;
- `SHA256SUMS.txt` для проверки скачанных байтов;
- журнал `android-export.log`.

**Это только отладочный APK для собственных устройств**. Он не предназначен для публикации в магазинах приложений, не содержит реальной игровой экономики и не доказывает стабильных 60 FPS. Сборка подписывается **новым временным debug-ключом в каждом запуске**, без публикации приватного ключа. Если установлена более ранняя QA-сборка с другой подписью, её нужно удалить перед установкой новой; иначе Android правильно откажет в обновлении.

## Проверка на устройстве

1. Скачать артефакт из успешного workflow в GitHub Actions и извлечь APK из ZIP.
2. Установить тестовое приложение в Android 13 или новее, соблюдая системные предупреждения о приложениях из внешних источников. Никаких специальных разрешений для игры не требуется.
3. Проверить открытие мира, видимость PBR-текстур, берег и рябь, зиму/лёд при пролистывании сезонов, управление камерой, смену ориентации.
4. Открыть «Показать диагностику» и запустить «Измерить производительность камеры (8.8)». Отчёт `user://world-camera-8-8-device.json` запишет p50/p95/p99 интервала кадров, кеш и память Godot; при наличии буфера обмена JSON копируется автоматически.
5. Сравнить реальный FPS, задержки, нагрев, плавность и артефакты с программными кадрами из `docs/WORLD-STAGE-9-4.md`. Пометка `headless=false` и поддержка OpenGL не гарантируют, что аппаратная проверка реально выполнена: она должна быть подтверждена на самом устройстве.

**Статус 9.4 остаётся неполным**, пока не проведены ручная визуальная и аппаратная приёмки. Проход CI удостоверяет только возможность получения подписанного APK и корректность файлового пакета.
