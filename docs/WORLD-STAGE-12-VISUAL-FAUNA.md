# Этап 12.9 — настоящие модели животных и проверка внешнего вида

## Сделано в PR #286

- Рендерер `wildlife_visuals.gd` читает **реальную численность** травоядных и хищников. Ни создание объекта Node3D, ни положение камеры не добавляет в популяции новых особей.
- В пределах радиуса камеры создаются максимум **16 экземпляров** `wildlife_visual_actor.gd`. Вне камеры нет тысяч узлов со скелетами и анимациями.
- Для каждого видимого животного создаётся настоящий импортированный `PackedScene` с `MeshInstance3D`, `Skeleton3D` и `AnimationPlayer`. **Никаких BoxMesh/SphereMesh на месте животных.** Если файл отсутствует, экземпляр не создаётся.
- Визуальный слой обновляется после расчёта физики суток и не читает изменяемые данные в момент работы `WorldDayRunner`. При загрузке нового мира визуальные экземпляры удаляются и размещаются заново по восстановленным стадам.
- `tools/install_fauna_assets.py` устанавливает ассеты **перед сборкой** и проверяет glTF-структуру, настоящие меши, скелеты, анимации и идентичность закреплённых Git-объектов зеркала. Источник, автор, лицензия CC0 и контрольная сумма указываются в `asset_provenance.json`.
- Рендер через Godot/Mesa создаёт реальный кадр `godot/output/fauna_real_models.png`, который прикрепляется к соответствующему GitHub Actions. Это **не** сгенерированный искусственным интеллектом макет.

## Визуальная и производственная приёмка

1. Установить оригинальные CC0-модели: `python3 tools/install_fauna_assets.py`. Оригинальные бинарные файлы не заменяются геометрическими заглушками.
2. Проверить импорт через Godot 4.7.2 и `godot --headless --path godot --script res://tests/world_wildlife_visuals_12_smoke.gd`. Тест отклоняет модель без минимум 8 костей и без анимаций.
3. Создать **действительный** кадр в Godot: `godot --path godot --script res://tests/world_wildlife_capture_12.gd`. В безэкранном Linux CI используется программный рендер Xvfb/Mesa и звук Dummy.
4. Провести художественную проверку всех видов на ближнем и среднем расстоянии, включая пропорции, деформацию скелета, цикл движения и взаимодействие хищник/жертва. Этот шаг нельзя заменить успехом компилятора.
5. На целевых ПК и Android замерить реальный FPS/p95 кадров, VRAM/RAM, влияние 1/8/16 одновременно видимых скелетов и сравнить LOD. Headless Linux CI измеряет только CPU-симуляцию без игрового рендера.

Две последние позиции **не выполнены**. 12.9 не следует закрывать, пока они не подтверждены и пока не утверждены все виды.
