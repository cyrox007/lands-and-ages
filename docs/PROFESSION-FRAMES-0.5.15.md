# 0.5.15 — покадровые наборы для автономных рабочих

## Что действительно изменено

Введён модуль profession-frames.js. На первом использовании профессии и действия он один раз растеризует атлас **768×576** из 32 отдельных ячеек (96×144, четыре направления по восемь кадров) и сохраняет его в памяти. В дальнейшем игра только берёт готовый кадр.

В отличие от старого painted-motion.js, где вращался фрагмент общего портрета, новые кадры состоят из самостоятельных слоёв левой и правой ноги, корпуса, обеих рук (плечо, локоть, ладонь), головы и рабочего инструмента. Изменяются суставы и позы; исходное утверждённое изображение сохраняет текстуру одежды, лица и обуви.

Подключены следующие действия:

| Профессия | Подготовленные атласы |
|---|---|
| Носильщик | walk, pickup, carry, unload |
| Строитель | walk, lay_foundation, assemble_frame, finish_roof |
| Лесоруб | walk, fell_tree, carry_logs |
| Каменотёс | walk, mine_stone, carry_stone |
| Земледелец | walk, harvest_crop, carry_crop |

Итого **17 наборов × 32 кадра = 544 отдельных кадра**. Сборка выполняется по требованию, не при каждом кадре игры. Для прочих ролей сохраняется предыдущий рендер. У носильщика используется изображение без нарисованного заранее мешка; игровой груз всегда рисуется отдельно.

Состояния выбираются из profession-actions.js, который учитывает реальные задачи движка и физическое расстояние при ходьбе. Промежуточные стадии работ, когда их нет в симуляции, не выдумываются. Грузы остаются привязаны к реальным данным.

## Проверки

- Node.js: присутствуют все 16 наборов, четыре направления и восемь кадров; фазы ног, рук, корпуса и инструмента различаются.
- Chromium: готовые атласы реально растеризуются из оригинального WebP; проверяются альфа-канал, различия пикселей между кадрами и ракурсами.
- Offline play.html содержит profession-frames.js и использует те же источники изображений.

## Что пока нельзя называть финальным артом

Эти наборы — **композиционная покадровая анимация** из утверждённых художественных изображений, с отдельными разрисованными рукавами, суставами и инструментами. Они не равнозначны 16 комплектам из 32 независимо вручную иллюстрированных изображений. Задний ракурс восстановлен приближённо (одежда/затылок), а не нарисован отдельно художником. Настоящая многовидовая художественная анимация рук/ног и тщательная проверка мобильного масштаба — дальнейший этап.

У носильщика механика получения/отдачи груза мгновенная: кадры для pickup/unload подготовлены, но без введения отдельной стадии симуляции не проигрываются задержкой.
