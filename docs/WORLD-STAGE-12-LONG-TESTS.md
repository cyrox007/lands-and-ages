# Этап 12.10 — длительная сезонная приёмка и оставшиеся аппаратные измерения

## Что действительно испытано

Godot 4.7.2, **полные природные сутки** через `WorldDayRunner`, реальная гидрология, почва, растительность, стихийные события, региональные стада травоядных и пищевые отношения хищников.

Один игровой год в Lands and Ages — **96 суток**, четыре сезона по 24 суток. Это игровое соглашение, не 365 астрономических дней.

| Параметр | Seed 1729 | Seed 1802 |
|---|---:|---:|
| Полных игровых лет | 2 | 1 |
| Сезонных суток | 192 | 96 |
| Исходно животных | 309 | 452 |
| Рождений | 314 | 261 |
| Смертей | 305 | 261 |
| Съедено хищниками | 182 | 214 |
| Осталось | 136 | 238 |
| CPU, p50 суток | 201,03 мс | 242,94 мс |
| CPU, p95 суток | 1177,23 мс | 1736,47 мс |
| Пик статической памяти Godot | 39,22 МиБ | 39,40 МиБ |
| Продолжение после загрузки | Совпадает | Совпадает |

Математическая проверка: `исходно + рождения − смерти − съедено = осталось`. После полного испытания создаётся настоящий `WorldSave`, восстанавливается независимая карта, и следующий день должен привести к одинаковым популяциям на обеих ветках.

Пройденный GitHub Actions: https://github.com/cyrox007/lands-and-ages/actions/runs/42677399110

Новое испытание воспроизводимо через:

```bash
godot --headless --path godot --script res://tests/world_wildlife_year_12_smoke.gd -- --seed=1729 --years=2
godot --headless --path godot --script res://tests/world_wildlife_year_12_smoke.gd -- --seed=1802 --years=1
```

Время одного игрового дня **НЕ равно времени кадра**. Годовой тест в Linux headless не измеряет игровую плавность, не отражает затраты на полноценный 3D-рендер, дисплей, VRAM и память ОС.

## Чего ещё нет для галочки 12.10

- [ ] Замеры живого OpenGL/Godot-кадра на целевом ПК: FPS, p95/p99 времени кадра, RAM и нагрузка GPU.
- [ ] Аппаратный тест на Android: реальные FPS, пропуски кадров, нагрев, расход ОЗУ и батареи.
- [ ] Нагрузочные испытания одновременно видимых 1/8/16 животных с настоящими скелетами, а также проверка масштабирования на десятки независимых регионов.
- [ ] Долгосрочный баланс хищников и травоядных на большем разнообразии seed и большем числе лет; отсутствие систематического исчезновения/перенаселения видов.
- [ ] Проверка возможных переиспользований/выделений памяти при смене карты и полном цикле загрузки игровых скелетных сцен.

Эти задачи нельзя закрыть по одной успешной headless CI-сборке. Заявление «оптимизировано для Android» без испытания на Android не допускается.

## Ограничения графического слоя

В каталоге 12.9 сейчас семь тестовых CC0 скелетных моделей, максимальное число видимых узлов — 16. Остальные животные пока живут только в данных популяций. Демонстрационный рендер не является окончательным художественным результатом и не включает полноценные бои/звуки/все виды. Подробности в `docs/WORLD-STAGE-12-VISUAL-FAUNA.md`.
