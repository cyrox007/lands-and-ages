# Референсы главного здания для объёмной Godot-архитектуры

Этот каталог содержит оригинальные концепты из исторического коммита
`53f7a047`. Материалы были восстановлены после удаления браузерного
прототипа и **не являются игровыми текстурами, билбордами либо
зависимостями runtime**.

- `author-concept.png` — авторский концепт-лист.
- `headquarters-level1.webp` ... `headquarters-level4.webp` —
  четыре последовательных архитектурных силуэта.
- `headquarters-foundation/frame/walls/roof/complete.webp` —
  стадии работ.
- `headquarters-light-damage/heavy-damage/fresh-ruins/old-ruins.webp` —
  ориентиры физического ущерба.
- `headquarters-module-*.webp` — элементы корпуса, ворот, флага,
  башенной крыши и загрузочной площадки.

**Текущая реализация:** `godot/scripts/world_headquarters_visual.gd`
строит полноценные MeshInstance3D, материалы и StaticBody3D из состояния
`WorldSettlement`. Физическая модель не читает данный каталог.

**Границы:** художественные WebP — исходный референс, а не
утверждённый финальный 3D-меш. Позднее детализацию, силуэты и
соответствие исходным изображениям следует оценить на устройствах,
не возвращая Canvas как второй игровой runtime.

## Художественный объёмный набор

В Godot используется не этот архив растровых референсов, а
[3D-комплект](../../../godot/assets/buildings/headquarters/headquarters_art.gltf),
созданный по мотивам зафиксированной формы четырёх уровней.
Модель хранит объёмную черепицу, фахверк, штучную кладку,
арочные ворота, фонари, башни и донжон.

Генератор полностью воспроизводим, исходный код и материалы
находятся в [tools/generate_headquarters_art.mjs](../../../tools/generate_headquarters_art.mjs).
Отладочная простая геометрия из версии 13.6 заменена.
